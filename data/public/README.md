# Public dataset

Every record committed here is synthetic until the reviewed collector and publisher milestones are delivered. The fixtures exercise product behavior; they are not news reports and do not represent real events or people.

Raw posts, copied articles, personal data, local file paths, Telegram sessions, private notes, credentials, and precise sensitive coordinates are prohibited. Future non-synthetic exports must pass the human publication and safety gate described in the architecture specification.

Every change must pass validation from `@syosint/schemas` before it can be built into the dashboard.
